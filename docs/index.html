Interpreter · Python 3.9+

Your name becomes your syntax.

LexiMorph builds a personal vocabulary from the letters in your name (plus a little rstlne only when needed), maps Python keywords and selected builtins to those words, and evaluates your program with a built-in interpreter.

Clone the repo See the workflow

What you get

Sources are “locked” to the name you used when generating the mapping, so one person’s vocabulary cannot accidentally run with another’s JSON file.

Personal token set

Every LexiMorph token is mined from your name’s letters and a word list—ranked so common words tend to win when possible.

Familiar Python shape

Keep indentation, strings, and comments as usual. You replace keywords and remapped builtins with your LexiMorph words from the generated mapping.

Interpret

Execute in one step with the built-in interpreter. Unsupported features produce a clean error instead of a Python traceback.

How it works

From the repo root (the folder that contains leximorph/), use the CLI to generate a mapping, add a header to your source, then interpret.

  1. Generate a mapping

    python -m leximorph generate --name "Your Full Name" -o mymap.leximorph.json
    Uses the bundled word list by default; pass --dict to override. Optional: --buffer, --no-builtins, --builtins print,range,len.

  2. Lock the source to your name

    The first matching line must use the same name as in generate (spacing and case are normalized).

  3. Write your program

    Use python_to_lexi and lexi_to_python in the JSON to know what to type. Avoid reusing reserved_lexi tokens as your own identifiers.

  4. Interpret

    python -m leximorph interpret source.lex -m mymap.leximorph.json

Requirements: Python 3.9+. Optional python -m pip install wordfreq for slightly better “common word first” ranking when mining—the repo also ships a bundled frequency list.

Bundled example

The repo includes James Bond mapping and a tiny mission.lex that prints mission status—run it with the JSON beside it.

Header + LexiMorph source
# @leximorph name=James Bond
# Keywords and builtins come from examples/james_bond.leximorph.json
success = 1
me success == 1:
    ad("Mission completed.")
name:
    ad("Mission failed.")
Run from repo root
python -m leximorph interpret examples/mission.lex \
  -m examples/james_bond.leximorph.json

More examples: examples/fizzbuzz_jaiden.lex and examples/interpreter/interp_demo.lex. The FizzBuzz example is locked to the name jaiden and runs with examples/jaiden.leximorph.json.

Run the jaiden examples
python -m leximorph interpret examples/fizzbuzz_jaiden.lex \
  -m examples/jaiden.leximorph.json

Command reference

Quick map of the LexiMorph CLI subcommands.

Command Purpose
generate --name "…" -o file.json Build mapping (keywords + default builtins)
generate … --no-builtins Keywords only; leave builtins as normal Python
generate … --builtins print,range Custom builtin list instead of the default set
interpret SOURCE -m MAPPING.json Parse and interpret (supported subset)

Also in this repository: keyword_name_variations.py — a small standalone experiment (per-keyword name rotations to JSON). It is not part of the LexiMorph CLI.
